# Sistema de Funcionarios

Software capaz de gerenciar funcionarios para um restaurante

## Visão Geral
- A classe Funcionario é o modelador que representa o objeto funcionario
- SistemaFuncionariosBomPrato é a classe que gerencia os funcionarios e utiliza do molde de métodos da interface 
SistemaFuncionarios
- Os funcionarios estão sendo armazenados em um MAP, que é passado como chave primaria o cpf do funcionario

## Tecnologias/Técnicas
- Classes do Java
- Classes para Test
- Interface
- Map
